# From SLI to NVSwitch

**The Technologies We Had to Kill to Build AI-Scale Networking**

A static blog post on the legacy technologies (SLI, PCIe-as-bus, kernel TCP/IP, best-effort Ethernet) that were replaced to make AI-scale networking possible.

By Piyush Gupta, Jeet Mane, Jai Chavan & Atharva Sheramkar.

## Run locally

```bash
python -m http.server 5500
```

Then open http://localhost:5500. No build step; it is plain HTML, CSS and JS, deployed with GitHub Pages from the `main` branch.
